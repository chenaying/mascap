# 批量推理结果解析指南

## 一、输出文件格式

### 1.1 文件位置

运行 `validation_meacap.py` 后，结果保存在：

```
{out_path}/{name_of_datasets}_generated_captions_meacap.json
```

**示例**：
- `--out_path ./checkpoints/train_coco` + `--name_of_datasets coco`
- → `./checkpoints/train_coco/coco_generated_captions_meacap.json`

### 1.2 JSON 文件格式

```json
[
    {
        "split": "valid",
        "image_name": "COCO_val2014_000000027440.jpg",
        "captions": [
            "A cute girl is sitting on a bed with a pink blanket.",
            "A young woman lies on a bed covered with a pink blanket."
        ],
        "prediction": "A cute girl sitting on a bed with a stuffed animal."
    },
    {
        "split": "valid",
        "image_name": "COCO_val2014_000000027441.jpg",
        "captions": [...],
        "prediction": "..."
    },
    ...
]
```

**字段说明**：
- `split`: 数据集分割（通常是 "valid"）
- `image_name`: 图像文件名
- `captions`: 真实标注（Ground Truth）列表
- `prediction`: 模型生成的描述

#### 方法 3：对比分析（EF vs 原方法）

```python
import json

# 读取两种方法的结果
ef_result_file = "checkpoints/train_coco/coco_generated_captions_meacap_ef.json"
original_result_file = "checkpoints/train_coco/coco_generated_captions_meacap.json"

with open(ef_result_file, 'r') as f:
    ef_results = {r['image_name']: r for r in json.load(f)}

with open(original_result_file, 'r') as f:
    original_results = {r['image_name']: r for r in json.load(f)}

# 对比相同图像的预测
common_images = set(ef_results.keys()) & set(original_results.keys())
print(f"共同图像数: {len(common_images)}")

# 找出预测不同的图像
different = []
for img_name in common_images:
    if ef_results[img_name]['prediction'] != original_results[img_name]['prediction']:
        different.append({
            'image': img_name,
            'ef': ef_results[img_name]['prediction'],
            'original': original_results[img_name]['prediction']
        })

print(f"预测不同的图像数: {len(different)}")
for diff in different[:5]:
    print(f"\n图像: {diff['image']}")
    print(f"EF方法: {diff['ef']}")
    print(f"原方法: {diff['original']}")
```

## 三、完整解析脚本示例

### 3.1 综合解析脚本

创建文件 `parse_validation_results.py`：

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-
"""
批量推理结果解析脚本
用法: python parse_validation_results.py <result_json_file>
"""

import json
import sys
import argparse
from collections import Counter
from typing import List, Dict

def load_results(file_path: str) -> List[Dict]:
    """加载结果文件"""
    with open(file_path, 'r', encoding='utf-8') as f:
        return json.load(f)

def basic_statistics(results: List[Dict]) -> Dict:
    """基本统计信息"""
    total = len(results)
    avg_length = sum(len(r['prediction'].split()) for r in results) / total if total > 0 else 0
    
    # 词频统计
    all_words = []
    for r in results:
        all_words.extend(r['prediction'].lower().split())
    word_freq = Counter(all_words)
    
    return {
        'total_images': total,
        'avg_caption_length': avg_length,
        'top_words': word_freq.most_common(20)
    }

def compare_results(file1: str, file2: str):
    """对比两个结果文件"""
    results1 = {r['image_name']: r for r in load_results(file1)}
    results2 = {r['image_name']: r for r in load_results(file2)}
    
    common = set(results1.keys()) & set(results2.keys())
    different = []
    identical = []
    
    for img_name in common:
        pred1 = results1[img_name]['prediction']
        pred2 = results2[img_name]['prediction']
        if pred1 != pred2:
            different.append({
                'image': img_name,
                'file1': pred1,
                'file2': pred2
            })
        else:
            identical.append(img_name)
    
    return {
        'common_images': len(common),
        'different': len(different),
        'identical': len(identical),
        'different_samples': different[:10]  # 前10个不同的样本
    }

def export_for_evaluation(results: List[Dict], output_file: str):
    """导出为 COCO 评估格式"""
    coco_format = []
    for r in results:
        coco_format.append({
            'image_id': r['image_name'],
            'caption': r['prediction']
        })
    
    with open(output_file, 'w', encoding='utf-8') as f:
        json.dump(coco_format, f, indent=2, ensure_ascii=False)
    
    print(f"已导出到: {output_file}")

def main():
    parser = argparse.ArgumentParser(description='解析批量推理结果')
    parser.add_argument('result_file', type=str, help='结果 JSON 文件路径')
    parser.add_argument('--compare', type=str, help='对比的另一个结果文件')
    parser.add_argument('--export', type=str, help='导出为评估格式的文件路径')
    parser.add_argument('--show-samples', type=int, default=5, help='显示样本数量')
    
    args = parser.parse_args()
    
    # 加载结果
    print(f"加载结果文件: {args.result_file}")
    results = load_results(args.result_file)
    
    # 基本统计
    print("\n=== 基本统计 ===")
    stats = basic_statistics(results)
    print(f"总图像数: {stats['total_images']}")
    print(f"平均描述长度: {stats['avg_caption_length']:.2f} 词")
    print(f"\n最常见的20个词:")
    for word, count in stats['top_words']:
        print(f"  {word}: {count}")
    
    # 显示样本
    print(f"\n=== 前 {args.show_samples} 个样本 ===")
    for i, r in enumerate(results[:args.show_samples]):
        print(f"\n图像 {i+1}: {r['image_name']}")
        print(f"预测: {r['prediction']}")
        print(f"真实标注数: {len(r['captions'])}")
        if r['captions']:
            print(f"示例标注: {r['captions'][0]}")
    
    # 对比分析
    if args.compare:
        print(f"\n=== 对比分析 ===")
        print(f"对比文件: {args.compare}")
        comparison = compare_results(args.result_file, args.compare)
        print(f"共同图像数: {comparison['common_images']}")
        print(f"预测相同: {comparison['identical']}")
        print(f"预测不同: {comparison['different']}")
        
        if comparison['different_samples']:
            print(f"\n前10个不同的预测:")
            for diff in comparison['different_samples']:
                print(f"\n图像: {diff['image']}")
                print(f"  文件1: {diff['file1']}")
                print(f"  文件2: {diff['file2']}")
    
    # 导出
    if args.export:
        print(f"\n=== 导出 ===")
        export_for_evaluation(results, args.export)

if __name__ == '__main__':
    main()
```

### 3.2 使用方法


## 四、评估指标解析

### 4.1 COCO 评估输出示例

运行 `evaluation/cocoeval.py` 后，输出类似：

```
Loading results from checkpoints/train_coco/coco_generated_captions_meacap.json...
Found 5000 predictions

Evaluating...
BLEU-1: 0.723
BLEU-2: 0.556
BLEU-3: 0.412
BLEU-4: 0.301
METEOR: 0.256
ROUGE-L: 0.523
CIDEr: 0.948
SPICE: 0.189
```

### 4.2 指标含义

| 指标 | 说明 | 范围 |
|------|------|------|
| **BLEU-1/2/3/4** | n-gram 精确度 | 0-1，越高越好 |
| **METEOR** | 考虑同义词的精确度 | 0-1，越高越好 |
| **ROUGE-L** | 最长公共子序列 | 0-1，越高越好 |
| **CIDEr** | 共识度（常用） | 0-10，越高越好 |
| **SPICE** | 语义精确度 | 0-1，越高越好 |

### 4.3 对比评估

```bash
# 评估 EF 方法
python evaluation/cocoeval.py \
    --result_file_path checkpoints/train_coco/coco_generated_captions_meacap_ef.json \
    > ef_results.txt

# 评估原方法
python evaluation/cocoeval.py \
    --result_file_path checkpoints/train_coco/coco_generated_captions_meacap.json \
    > original_results.txt

# 对比
diff ef_results.txt original_results.txt
```

```bash
ls -lh checkpoints/train_coco/
```

```python

import json
try:
    with open('result.json', 'r') as f:
        data = json.load(f)
    print("JSON 格式正确")
except json.JSONDecodeError as e:
    print(f"JSON 格式错误: {e}")
```

### 5.3 结果为空

检查：
1. 是否成功运行了 `validation_meacap.py`
2. `--out_path` 参数是否正确
3. 是否有足够的 GPU 内存
4. 图像路径是否正确

## 七、总结

### 7.1 输出文件

- **位置**：`{out_path}/{name_of_datasets}_generated_captions_meacap.json`
- **格式**：JSON 数组，每个元素包含 `image_name`, `captions`, `prediction`

### 7.2 解析方法

1. **Python 脚本**：直接读取 JSON 文件
2. **评估工具**：使用 `evaluation/cocoeval.py` 计算指标
3. **对比分析**：对比不同方法的结果

### 7.3 关键指标

- **CIDEr**：最常用的图像描述评估指标
- **BLEU-4**：n-gram 精确度
- **METEOR**：考虑同义词的精确度
